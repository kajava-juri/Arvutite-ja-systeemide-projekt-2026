## Fan switch: L298N module

Load: 14 V fan, 0.1 A

### 1. Voltage across the fan

    V_fan = Vs - V_drop = 14 V - 2 V = 12 V

### 2. Power dissipation

Output stage:

    P_out = V_drop * I_L = 2 V * 0.1 A = 0.2 W

Switching Losses: t_on=0.4 + 0.1 = 0.5 t_off=1 + 0.35=1.35(from datasheet)

     P_sw= 0.5 * 14V * 0.1A * 1.85 us * 25kHz = 32.4 mW

Quiescent power (probably should not use because I_L is not 0):

    P_Vs  = Vs * Is  = 14 V * 50 mA = 0.7 W
    P_Vss = Vss * Iss = 5 V * 7 mA = 0.035 W

Total:

    P_tot = 0.2 + 0.7 + 0.035 = 0.935 W

    or 
      P_tot = 0.2 W + 0.0324 W = 232.4 mW

### 3. Thermal calculation

R_thJA with a heatsink :

    R_thJA = R_thJC + R_th(case-sink) + R_th(sink-ambient)
           = 3 + 1 + 20 = 24 °C/W   (estimate for the small L298N board heatsink. The heatsink value is not given by the manufacturer.) 
           
Junction Temperature :   

    T_j = T_a + P_tot * R_thJA
    40 °C + 0.257 W * 24 °C/W  = 46.2 C
    
Maximum heat sink power:

    P_max = (T_j(max) - T_a) / R_thJA
    P_max = (130 - 25) / 24 = 4.4 W
    P_max = (130 - 40) / 24 = 3.75 W
    Maximum junction temperature = 130 C
